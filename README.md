# Tilemap Studio

Бесконечный 2D-редактор тайловых карт в браузере. Рисуйте местность, расставляйте объекты (дома, деревья, дороги), настраивайте поведение клеток (коллизии и перекрытия) и сразу проверяйте результат в режиме героя — с плавным движением и сортировкой по глубине.

Проект собран на **Vite + ES-модулях**, без фреймворков и без бэкенда: всё живёт в браузере, карта сохраняется в JSON и экспортируется в PNG.

---

## Возможности

- **Бесконечный мир** на чанках 16×16 тайлов (тайл 32×32 px) — создаются только те чанки, где что-то нарисовано.
- **Три слоя клетки** с разделением «визуал / поведение»:
  - `floor` — видимая текстура terrain (рисуется всегда);
  - `walls` — невидимый флаг «блок» (герой не пройдёт);
  - `overhead` — невидимый флаг «проходимо, герой под объектом/кроной».
- **Инструменты**: кисть, прямоугольник, линия, заливка (flood fill), пипетка, выбор/перенос объектов.
- **Объекты двух категорий** (категория задаётся папкой файла):
  - `road` — плоские «продолжения terrain»: всегда проходимы, без маски, рисуются под всеми сущностями;
  - `environment` — декор/здания с типовой маской (нижний ряд = `walls`, остальное = `overhead`).
- **Мульти-тайлсет** с глобальными id тайлов и закреплением диапазонов в файле карты.
- **Режим героя**: плавное WASD-движение без привязки к сетке, коллизии по ногам, сортировка по глубине (painter's algorithm), тумблер «Сквозь перекрытия».
- **Undo/redo** единым стеком batch-операций (рисование тайлов и объектные действия откатываются вместе).
- **Мини-карта**, **сохранение/загрузка JSON** и **экспорт PNG**.
- Тёмный интерфейс, SVG-иконки, горячие клавиши на каждое действие.

## Быстрый старт

Нужен Node.js 18+.

```bash
# установка зависимостей
npm install

# режим разработки (Vite dev server, http://localhost:3000)
npm run dev

# production-сборка в dist/
npm run build

# предпросмотр собранной версии
npm run preview
```

Dev-сервер запускается на порту **3000** и сам открывает браузер (см. [vite.config.js](vite.config.js)).

## Управление

### Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `1` / `2` / `3` | Активный слой: Тайлы (floor) / Блок-флаг (walls) / Overhead-флаг |
| `B` | Кисть |
| `R` | Прямоугольник |
| `L` | Линия |
| `F` | Заливка (toggle) |
| `I` | Пипетка |
| `V` | Выбор объекта |
| `E` | Ластик (toggle) |
| `G` | Показать / скрыть сетку |
| `H` | Режим героя (симуляция) |
| `T` | В режиме героя — показывать героя сквозь перекрытия |
| `[` / `]` | Уменьшить / увеличить размер кисти |
| `Delete` / `Backspace` | Удалить выделенный объект |
| `Esc` | Отмена (перенос → расстановка → выделение) |
| `Ctrl + Z` | Отменить |
| `Ctrl + Y` / `Ctrl + Shift + Z` | Повторить |
| `W` `A` `S` `D` | Движение героя (в режиме героя) |

### Мышь

| Действие | Что делает |
| --- | --- |
| **ЛКМ** | Рисовать / поставить объект |
| **ПКМ** | Стирать на активном слое / отменить расстановку |
| **Колесо** | Масштаб (зум к курсору) |
| **Средняя кнопка** | Панорамирование |
| **Shift + кисть** | Провести линию от последней точки |

## Как устроена модель мира

- **Сетка** 32×32 px, мир разбит на **чанки** 16×16 тайлов. Чанк хранит три плоских массива: `floor[]`, `walls[]`, `overhead[]`.
- На одной клетке поведение **одно из трёх** (`floor` / `walls` / `overhead`) — флаги взаимно вытесняют друг друга.
- **Ластик на слое `floor` работает каскадом**: первый клик снимает невидимые флаги (текстура остаётся), второй — стирает саму текстуру. Слои `walls`/`overhead` снимают только свой флаг.
- **Объекты** — это отдельные инстансы-картинки поверх сетки (`{ id, file, w, h, gx, gy }`, где `gx,gy` — верхний-левый тайл). Их поведение хранится не в самом инстансе, а в виде флагов `walls`/`overhead` в чанках — поэтому коллизии и сортировка «бесплатны».
- **Пересечения**: `environment` можно ставить поверх `road`; `road` поверх `road`/`environment` — нельзя (дороги стыкуются по рёбрам). При переносе/удалении объекта затрагиваются только те клетки, которыми он **владеет** (верхний объект над клеткой).
- **Заливка** двухфазная (сначала сбор области, потом покраска) с предохранителем `FILL_REGION_LIMIT`, чтобы заливка по «бесконечной» пустоте не подвешивала редактор.

## Формат сохранения (JSON)

Карта сохраняется в файл `tilemap.json` в формате **v3**:

```json
{
  "version": 3,
  "tilesets": [{ "file": "tileset_1.png", "start": 0, "count": 560 }],
  "chunks": {
    "0,0": { "floor": [-1, 3, "..."], "walls": ["..."], "overhead": ["..."] }
  },
  "objects": [
    { "id": 1, "file": "environment/tree.png", "w": 3, "h": 4, "gx": 10, "gy": -2 }
  ]
}
```

- Глобальный id тайла = `start` тайлсетового диапазона + локальный id внутри картинки. Диапазоны **замораживаются в файле карты**, поэтому добавление рядов тайлов не «съезжает» на старых картах.
- Форматы **v2** (чанки + объекты) и более старые (только чанки) по-прежнему читаются.
- **Правило эволюции реестра тайлсетов**: файлы только добавляются в конец списка — удалять и переставлять нельзя.

## Как добавить ассеты

### Новый тайлсет
1. Положите PNG в `public/tilesets/` (кратный 32 px, режется по тайлам автоматически).
2. Добавьте строку **в конец** реестра `TILESET_FILES` в [src/tileset.js](src/tileset.js).

### Новый объект
1. Положите PNG в нужную папку категории: `public/objects/environment/` или `public/objects/road/`.
2. Добавьте строку в реестр `OBJECT_FILES` в [src/objects.js](src/objects.js), указав путь с папкой категории, например `environment/rock.png`. Размер `w×h` в тайлах вычисляется из PNG автоматически.

## Технологии

- [Vite](https://vitejs.dev/) — dev-сервер и сборка;

- HTML5 Canvas 2D — рендеринг мира, мини-карты и экспорта;
