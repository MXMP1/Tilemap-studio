> «Память проекта»: как устроен редактор, что делаем сейчас, открытые вопросы и принятые решения.
> Двигаемся медленно, по одному этапу, ничего не теряя.

---

## 1. Модель мира (структура данных НЕ меняется)

- **Сетка 32×32**, чанки 16×16, мир бесконечный.
- **Чанк** содержит три массива: `floor[]`, `walls[]`, `overhead[]` — и смысл у них теперь такой:
  - `floor` — **визуальный тайл terrain** (текстура земли/дороги). Рисуется всегда. + поведение по умолчанию «ходим».
  - `walls` — **НЕВИДИМЫЙ флаг** «блок»: герой не пройдёт. Текстура не рисуется, только красная рамка при сетке.
  - `overhead` — **НЕВИДИМЫЙ флаг** «проходимо, герой под» (например объект-дерево поверх героя). Зелёная рамка при сетке.
- **Объекты** — отдельные инстансы-картинки (tree.png, barrel.png, clock.png…), ставятся ПОВЕРХ тайлов на сетку (кратно 32×32, могут быть вытянутыми: 160×96 и т.п.).
- На клетке поведение одно из трёх: floor / wall / overhead — как и сейчас (вытеснение).

---

## 2. Правила работы редактора (согласовано 03.09)

- **Рисование terrain**: клик по тайлу во вкладке «Terrain» → режим кисти, рисуем тайл в `floor`, поведение клетки становится floor (по умолчанию).
- **Расстановка объектов**: клик по объекту во вкладке «Objects» → режим расстановки объектов. Можно ставить НЕСКОЛЬКО объектов подряд (сколько угодно). Выход — клик по любому тайлу terrain или переключение на любой инструмент рисования.
- **Поведение (краска-невидимка)**: отдельный инструмент, НЕ из палитры. Слой 1/2/3 задаёт, какой флаг красим: 1=floor(снять все флаги), 2=wall, 3=overhead. `floor` (текстуру) не трогает.
- **Курсор**: если ничего не выбрано — пустой квадратик в сетке (как в начале, ничего не нарисовано). При выборе объекта перед установкой — жёлтая рамка 1px по периметру (превью), можно добавить полупрозрачность.
- **Объекты и поведение**: у каждого типа объекта есть типовая маска поведения (какие его клетки wall, какие overhead); маску можно дорисовать/поправить для конкретного инстанса; при переносе объекта маска переезжает вместе с ним.

## 5. Журнал решений

- 2026-09-03 — Модель «гибрид»: земля/дороги = тайлы в сетке; дома/декор = объекты-инстансы.
- 2026-09-03 — Дом декоративный; сначала поставить/удалить; объекты отдельные, без группировки; дороги — в землю (floor).
- 2026-09-03 — Поведение клетки одно (floor/walls/overhead взаимозаменяемы); несколько визуалов на клетке — через объекты.
- 2026-09-03 — Ластик (E) и ПКМ стирают только на активном слое (сделано в chunks.js).
- 2026-09-03 — Визуал и поведение разделяем СМЫСЛОВО: floor = текстура (рисуется), walls/overhead = невидимые флаги. Структуру чанков НЕ меняем.
- 2026-09-03 — Отдельный инструмент «Объект» НЕ нужен: выбор объекта в палитре сам включает режим расстановки (несколько подряд), выход — тайл terrain или другой инструмент.
- 2026-09-03 — Курсор без выбора — пустой квадрат в сетке; превью объекта — жёлтая рамка 1px.
- 2026-09-03 — Папки: `public/tilesets/` + `public/objects/`.
- 2026-09-03 — Активный тайлсет — `tileset_1.png` (256×2240, 8×70 тайлов).
- 2026-09-03 — Этап 2 (код): walls/overhead = невидимые флаги (маркер FLAG_TILE_ID=1, рендер/мини-карта/PNG — только floor). Клик палитры/пипетка возвращают слой 1. Заливка флагов по области с тем же поведением. Подписи слоёв в UI обновлены.
- 2026-09-03 — Ластик (каскад): слой 1 — первый клик снимает флаги 2/3 (текстура остаётся), второй — текстуру; заливка-стирание чистит область целиком (тайл + флаги). Слои 2/3 снимают свой флаг точечно.
- 2026-09-03 — Этап 3 (код): вкладки «Тайлы/Объекты» со сворачиванием по заголовку; `selectedTileId` по умолчанию null → пустой квадрат-курсор, рисование без выбора запрещено (null ≠ -1, чтобы не стереть случайно); вкладка Объекты — плейсхолдер до этапа 4.
- 2026-09-03 — Этап 4 (код): объекты-инстансы {id, file, w, h, gx, gy} (gx/gy = верх-левый тайл); поведение = флаги walls/overhead в чанках (инстанс их не хранит) → коллизии и сортировка бесплатны. Маска по умолчанию: низ = walls, верх = overhead. Якорь: нижний ряд у курсора. Инструмент «Выбор» [V] (по ответу пользователя): ЛКМ выделяет/тащит (маска едет с ним), Delete/Backspace удаляет, Esc/клик в пустое снимает; расстановка из вкладки «Объекты» — несколько подряд до отмены. Undo/redo — единый стек batch-операций {tile | objects-снимок}; каждая объектная операция откатывается одним Ctrl+Z вместе с флагами маски. Слой 1 не трогает клетки footprint (защита маски), слои 2/3 — свободная правка маски. JSON v2 (version, chunks, objects), старые файлы читаются; PNG-экспорт с объектами.
- 2026-09-03 — Фикс (проверка этапа 4 в браузере): флаг overhead на ТАЙЛЕ не прятал героя — текстура клетки рисовалась только в первом проходе (под героем), герой шёл «по верху» куста/кроны. Объекты прятали героя корректно (painter-проход рисует их после героя), а для тайлов такого прохода не было. Добавлен проход drawOverheadOverHero: после героя текстуры клеток с флагом overhead дорисовываются ПОВЕРХ героя, если клетка пересекает его спрайт (голова+ноги). Поведение объектов и walls-флагов не менялось.
- 2026-09-03 — По ходу проверки: дорисовка overhead-тайла поверх героя «дырявила» картинку объекта (текстура земли под footprint рисовалась поверх спрайта объекта). Исправлено: проход drawOverheadOverHero пропускает клетки под footprint объектов (объект сам решает, что видно). По просьбе пользователя добавлен тумблер «Сквозь перекрытия» [T] (кнопка в верхней панели, появляется только в режиме героя): перекрывающие спрайт героя объекты (alpha 0.3) и overhead-дорисовки тайлов становятся полупрозрачными, герой видно. Действует и на тайлы, и на объекты; состояние не сбрасывается при выходе из симуляции; на экспорт PNG/мини-карту не влияет.
